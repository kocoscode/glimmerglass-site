Inside Framer

Artwork in.
Component out.

Drop your original animation into Glimmerglass. It creates the videos and player, uploads the finished media to Framer, and places the complete component in your project.

Marketplace release and purchasing are being prepared. This guide describes the implemented workflow; a public installation link will be added when the release is available.

  1. Open Glimmerglass in your Framer project.The paid release uses the license key delivered with your purchase. Activate it once in each browser profile you use.
  2. Add a file or PNG folder.Use transparent animation source files. You don’t need an existing component or a player file.
  3. Adjust the settings.Choose the component name, quality and description. PNG sequences offer frame-rate choices; timed sources retain their own timing. Changing quality updates estimates without converting.
  4. Press Create Component.Your selected files are uploaded for conversion. After conversion, Glimmerglass uploads the finished media to your Framer project, creates the Code File and places the component on the page.
  5. Inspect and use it.Check the encoded result with Size Preview and the background controls. Open Framer Preview to see the placed component. Download is available if you also want the portable bundle.

When something interrupts creation

Conversion finished, but insertion failed

Keep the plugin open and use Retry. Glimmerglass retains the converted files and successful uploads during that session. If the error says a file already exists, the plugin uses a unique name to preserve your existing work.

“This origin is not allowed”

The conversion service hasn’t accepted the address this plugin is running from. This is a service configuration problem, not a problem with your PNG folder. Send support the error and whether you opened a Marketplace or review version; do not send a license key.

The service is busy or unavailable

Try again later. Cloud conversion needs a working connection and available capacity, even when your saved license remains unlocked. An already-created component does not depend on the converter service to play.

The file is too large

The hosted converter accepts up to 256 MiB of source files, 600 PNG frames, 16 megapixels per frame and 120 seconds of animation. Export a shorter source or reduce its original dimensions, then try again.

License help

The planned Framer offer is a one-time purchase with three browser activations. Final price and service terms will be shown at checkout when sales open. The Apple app is a separate App Store purchase.

How do I move to another browser or computer?

Choose Deactivate this device in the plugin before moving. Once deactivation succeeds, activate the same key in the new browser. Each browser profile has its own saved activation.

I cleared browser data and lost my activation

Clearing site data also clears the saved instance. Contact support with your order reference so we can help recover the activation. Never post your complete key publicly.

Can I work offline?

A previously validated license can remain unlocked for up to 14 days during a validation outage. Creating a new component still requires the conversion service and Framer uploads. Existing components keep working from the media stored in your project.

Does an update overwrite my component edits?

No. New creations use a unique Code File name instead of replacing an existing file. Keep your edited component until you have checked the new one.
